## MyAccountBook：修复 `git push` SSH 主机密钥报错
- 现象：`git push -u origin main` 报"Host key verification failed / 无法读取远程仓库"。
- 根因：`~/.ssh/known_hosts:3` 中 github.com 旧 RSA 密钥与 GitHub 当前密钥不匹配（GitHub 官方轮换过主机密钥）。
- 修复：`ssh-keygen -R github.com` 移除旧记录（备份在 `~/.ssh/known_hosts.old`），重连后保存新密钥；指纹已核对为 GitHub 官方值（ED25519 `SHA256:+DiY3wvvV6TuJJhbpZisF/zLDA0zPMSvHdkr4UvCOqU`）。
- 结果：push 成功，`main` 已跟踪 `origin/main`；远程仓库 `git@github.com:luchao008/MyAccountBook.git`，GitHub 用户名 luchao008。
