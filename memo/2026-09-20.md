## 二、后端修复：Midway v4 ctx 注入（8ea0be3）

**文件**：`src/admin/admin-auth.controller.ts`

**问题**：`async me(@Inject() ctx: Context)` 在**方法参数位置**用 `@Inject()`。
Midway v4 没有 `@Ctx` 装饰器，方法参数的 `@Inject()` 被当作「按名字注入依赖」，
触发 `MidwayDefinitionNotFoundError`（`Definition for "[object Object"`）。

**修复**：改为**属性注入** `@Inject() ctx: Context;`，方法内用 `this.ctx.admin.adminId`。
已加注释说明此坑。

## 四、⚠️ 操作按钮「有属性无样式」的根因（bf498e4）

### 现象

用户列表操作列按钮无论 `ghost` 还是 `primary` **都没有任何样式**；
DevTools 里 `<a-button>` 被渲染成**原生未知元素**（`custom-element`），属性在但样式不生效。

### 根因（关键）

**Vben Admin v5 的 `bootstrap.ts` 只 `app.use(router)`，不全局注册 ant-design-vue。**
所以模板里写 `<a-button>`/`<a-space>` 这种 kebab 标签，Vue 解析不到组件，
fallback 成原生标签 → 无任何 antd 样式。对比状态列的 `<Tag>` 因**在 script 里显式
import** 所以正常。

### 修复

```ts
// list.vue script
import { Button, message, Modal, Space, Tag } from 'ant-design-vue';
```
模板改用 PascalCase `<Button>` / `<Space>`。

### 配色（luchao 要求两个按钮不同色）

ant-design-vue 4.2.6 的 Button **没有 `warning` prop**（`type` 只支持
primary/default/dashed/text/link，危险色只有 `danger` 布尔）。最终三色方案：

| 操作 | 颜色 | 实现 |
|---|---|---|
| 通过 / 启用 | 蓝 | `type="primary"` |
| 停用 | 橙 | 内联样式，项目 warning token `hsl(42,84%,61%)` |
| 驳回 / 删除 | 红 | `type="primary" danger` |

> 教训：**Vben v5 模板里的 antd 组件必须显式 import，不能靠 kebab 标签。**
