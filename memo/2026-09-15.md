### 折叠的实现

```ts
/** 折叠时展示的条数（与参考图一致：默认 5 条 + 「点击展开」） */
const COLLAPSED_COUNT = 5;
const expanded = ref(false);

/** 折叠态：默认只显示前 COLLAPSED_COUNT 条；展开后显示全部 */
const visibleRanking = computed(() =>
  expanded.value ? ranking.value : ranking.value.slice(0, COLLAPSED_COUNT)
);
```

模板里 `v-for` 由 `ranking` 改为 `visibleRanking`，列表末尾加：

```html
<view v-if="ranking.length > COLLAPSED_COUNT" class="rank-toggle" @click="expanded = !expanded">
  <text class="rank-toggle-text">{{ expanded ? '收起' : '点击展开' }}</text>
  <SvgIcon :name="expanded ? 'icon-chevron-up' : 'icon-chevron-down'" :size="12" />
</view>
```

与 RankList.vue（报表页用）的 `.toggle` 是**同一套做法**，交互一致。

### 顺带修：CRLF 行尾

HomeView.vue 整份文件是 **CRLF** 行尾。MEMORY.md 里记过这个坑
（CRLF 会让 `curl -w` 返回值带 `\r`，`[ "$2" = "$3" ]` 判等失败 → 6 个回归用例假失败）。
本次用 `perl -i -pe 's/\r\n/\n/g'` 归一为 LF，否则 `edit` 工具匹配不上（**就是这一步卡住了两次**）。

> 教训：**`edit` 的 old_string 匹配不上时，先 `od -c` 看一眼行尾符**，别反复重试。

### 一个实现取舍：「确定」直接生效，不回到面板再点一次

类型弹层是**独立弹层**，它的「确定」直接写 filterModel.types 并 reloadAll()，
**不经过筛选面板的 draft** —— 用户在这一层点「确定」的预期就是立即生效（参考图也是这个交互），
若还要回面板再点一次，用户会以为点了没用。筛选面板下次打开会从 props.model 重新同步（watch visible），
所以不会残留旧值。
