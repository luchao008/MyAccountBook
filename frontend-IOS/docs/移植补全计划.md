## 四、P2 报表图表

- ABRingChart：Core Graphics 手绘环形图，Top 6 + 其他，扇区留 gap，

## 十二、第五轮：离线记账队列（2026-09-25）

对齐 frontend/src/utils/offline.ts。范围刻意压小：**只支持离线新增**，
不支持离线查询/编辑/删除 —— 因此不存在冲突问题，联网后就是普通新增。

### 实现

- **ABOfflineQueue**：队列持久化到 NSUserDefaults，每条带 UUID clientId
- **ABNetworkMonitor**：AFNetworking Reachability 监听网络状态
- **记一笔**：离线时直接入队；在线请求失败也入队（避免用户白填）
- **AppDelegate**：启动时补传 + 联网恢复时补传 + 回前台补传
- **流水页**：监听 ABOfflineFlushedNotification 自动刷新

### 幂等（已验证）

后端 `(user_id, client_id)` 唯一约束。实测：同一 clientId 提交两次，
只落一条记录（第二次返回的是第一次的 id）。

## 十三、UI 对齐重构（2026-09-25 收尾）

> luchao 反馈「UI 上没有对齐前端」。经用 playwright 抓取前端真实截图逐页比对，
> 发现**结构级理解错误**（不是细节问题），并逐页重写。

### 根本问题

最初是照页面文件名清单「猜」的结构，没真正打开前端看。实际结构：

- 账本选择页（启动页）自带 TabBar：**首页 / 我的**
- 首页是单页容器，内含 HomeView，带 TabBar：**流水 / 记一笔 / 报表**
- 记一笔是「金额卡 + 分类/日期/备注行 + 底部键盘」而非分段控件
- 分类管理是「分组树 + 底部操作栏」而非平铺列表

### 逐页重写

| 页面 | 关键改动 |
|---|---|
| 登录页 | 加顶部导航栏；输入框白底+描边（原灰底填充） |
| 账本选择页 | 居中标题 + 列表（图标/默认徽标/创建日期）+ 新建按钮 + TabBar |
| 首页（新增） | 金色 banner + 区间卡（今天/本周/本月/本年/去年）+ 分类排行 + 底部栏 |
